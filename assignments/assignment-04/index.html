Assignment 4

Create a Dashboard

Create a web app in ArcGIS Online that uses charts, maps, etc. to communicate geographic information.

An ArcGIS Online Dashboard is a template for a web app that uses panels to display different information as text, maps, graphs, images, or other media.

Data

This assignment will be based on a dashboard tutorial you choose from Esri’s ArcGIS Dashboards tutorials. Each dashboard tutorial has its own data layer and use case.

  • Los Angeles Healthcare Facilities
  • Simulated real-time incidents
  • Simulated snow plows
  • Data collection app for damage assessment
  • Global COVID-19 cases and deaths

Steps

  1. Go to the ArcGIS Dashboards tutorials page.
  2. Choose one of the dashboard tutorials to complete and submit for this assignment.
    • The goal in each tutorial is to produce a functional dashboard that communicates information. You do not need to complete every step in every tutorial. Read ahead through the tutorial steps before starting to judge whether you can skip parts without compromising the goal of delivering a functional, effective app.
  3. Once you are satisfied with your dashboard, make sure it is shared with “Everyone”.
  4. Fill out the Item Details page explaining the purpose of your app and what it does, along with any helpful links to layers etc.
  5. Copy the short URL for your dashboard’s Item Details page.
info You do not need to complete every step in the longer tutorials.

Submit

  1. The URL to the Item Details page of your dashboard app. Example: https://arcg.is/ABC123
